# h3_dns_zone (Resource)

Authoritative DNS zone of a project in the h3dns service. A new zone is `pending_verification` until its delegation to `nameservers` (or the TXT `verification_txt_name` = `verification_txt_value`) is seen; record sets can be prepared before that and are published when the zone becomes `active`.

## Example Usage

```terraform
resource "h3_dns_zone" "main" {
  project_id  = var.project_id
  name        = "example.com"
  dnssec      = true
  default_ttl = 300
}
```

## Schema

### Required

- `name` (String) Zone name, e.g. `example.com` (IDN allowed, stored as A-labels)

### Optional

- `default_ttl` (Number) Default TTL for record sets without `ttl` (60-86400)
- `dnssec` (Boolean) Sign the zone (ECDSA P-256 CSK, NSEC3). Publish `ds_records` at the registrar. Turning it off is refused while the parent still has a DS.
- `force_destroy` (Boolean) Delete the zone even if platform-managed record sets (LB, EIP, DB, certificates) exist in it
- `labels` (Map of String) Free-form labels
- `project_id` (String) Project ID (UUID). Defaults to the provider `project_id` (`H3_PROJECT_ID`). Changing it replaces the zone.
- `verification_method` (String) `ns` (delegation, default) or `txt`. The service may require `txt` (competing claim or a name already delegated to the platform).

### Read-Only

- `dnssec_state` (String) `unsigned`, `signing`, `waiting_ds`, `secure`, `unsigning`
- `ds_records` (List of String) DS records for the registrar
- `id` (String) Zone ID
- `nameservers` (List of String) Delegate the domain to these name servers
- `status` (String) `pending_verification`, `active`, `suspended`, `deleting`
- `verification_txt_name` (String) TXT owner name for the `txt` method (while pending)
- `verification_txt_value` (String) TXT value for the `txt` method (while pending)
