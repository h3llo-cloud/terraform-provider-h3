# h3_security_group_rule (Resource)

One rule of a security group, managed separately from the group. Use it only on groups without inline `rule` blocks in
`h3_security_group`. Any change replaces the rule. Several rule resources of one group can be applied in parallel.

## Example Usage

```terraform
resource "h3_security_group_rule" "pg_from_web" {
  security_group_id        = h3_security_group.db.id
  direction                = "ingress"
  protocol                 = "tcp"
  port_from                = 5432
  remote_security_group_id = h3_security_group.web.id
}
```

## Schema

### Required

- `direction` (String) `ingress` or `egress`.
- `security_group_id` (String) Security group ID.

### Optional

- `action` (String) `allow` (default) or `deny`.
- `description` (String) Free text, up to 255 characters.
- `port_from` (Number) First port (tcp/udp). Unset = all ports.
- `port_to` (Number) Last port (tcp/udp). Unset = `port_from`.
- `priority` (Number) 1..170, lower is evaluated first. Default 100.
- `protocol` (String) `all` (default), `tcp`, `udp` or `icmp`.
- `remote_cidr` (String) IPv4/IPv6 CIDR or address of the peer. Conflicts with `remote_security_group_id`.
- `remote_security_group_id` (String) Peer security group of the same project.

### Read-Only

- `id` (String) Rule ID.

## Import

```shell
terraform import h3_security_group_rule.pg_from_web <security_group_id>/<rule_id>
```

Rule ids are listed by the `h3_security_group` data source (`rules[*].id`).
