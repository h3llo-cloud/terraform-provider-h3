# h3_dns_ptr (Resource)

Reverse DNS (PTR) of an EIP of the project. `hostname` must already resolve to the EIP address (forward-confirmed reverse DNS): create the A/AAAA record first and add `depends_on`. Destroy resets the PTR to the platform default (`ip-a-b-c-d.<region>.ip.<svc-zone>`).

## Example Usage

```terraform
resource "h3_dns_ptr" "mail" {
  project_id = var.project_id
  eip_id     = h3_eip.mail.id
  hostname   = "mail.example.com"
  depends_on = [h3_dns_recordset.mail]
}
```
