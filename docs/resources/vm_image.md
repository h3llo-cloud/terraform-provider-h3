# h3_vm_image (Resource)

~> **PREVIEW.** Custom images are a preview feature.

Manages a custom VM image of a project: imported from an HTTPS URL (qcow2 or raw, optionally `.gz`/`.xz`) or copied from the root disk of a **stopped** VM of the project. Create a VM from it with `h3_vm.image = h3_vm_image.x.image` (`custom:<id>`) and `disk_size` not below `size_gi`. The image must be a Linux image with cloud-init. Apply waits until the image is `READY` (up to 60 minutes, see `timeouts`); a failed import fails the apply with the platform message, and the image is then replaced on the next apply. Every argument replaces the image. VMs made from an image are full copies and do not depend on it. Limits: 10 images per project, up to 256 GiB each.

## Price and limits

- Storage of an image is billed at **12 ₽ per GiB per month** of its virtual size (`size_gi`), from creation until the
  image is deleted. There is no free volume. Billing item `VM_IMAGE_STORGB` (same price as `R_BASIC_STORGB`).
- Up to **10 images per project**, each up to **256 GiB**.
- Creating an image needs a workspace balance above zero.
- Imported files are not scanned for viruses: import only images you trust.

## Upload an image from your computer

The import takes an HTTPS URL. To import a file from your computer, put it into your own S3 bucket and pass a presigned
link to it:

1. Upload the `qcow2` or `raw` file (optionally `.gz`/`.xz`) into a bucket of your project in h3s3. The object is billed
   at the S3 tariffs; you can delete it once the image is `READY`.
2. Make a presigned GET URL with the project S3 keys and the endpoint `https://storage.h3llo.cloud` (any S3 client;
   in the console: «Из бакета S3»). The link must stay valid until the import ends:

   ```shell
   aws --endpoint-url https://storage.h3llo.cloud s3 cp ./my-image.qcow2 s3://my-bucket/images/my-image.qcow2
   aws --endpoint-url https://storage.h3llo.cloud s3 presign s3://my-bucket/images/my-image.qcow2 --expires-in 86400
   ```

3. Pass the URL as `url` and set `size_gi` not below the virtual size of the file (`qemu-img info`):

   ```terraform
   resource "h3_vm_image" "mine" {
     name    = "my-image"
     url     = var.presigned_url # sensitive: keep it out of the code
     size_gi = 20
   }
   ```

The API (`POST /api/vms/v1/images/custom` with `projectId`, `name`, `url`, `sizeGi`, `firmware`) does not return the
query string of the link.

## Example Usage

```terraform
# Import a cloud image over HTTPS (qcow2 or raw, optionally .gz/.xz).
resource "h3_vm_image" "alma" {
  project_id = var.project_id
  name       = "almalinux-9"
  url        = "https://repo.almalinux.org/almalinux/9/cloud/x86_64/images/AlmaLinux-9-GenericCloud-latest.x86_64.qcow2"
  size_gi    = 10 # virtual size, not below the size inside the file

  timeouts {
    create = "90m" # default 60m
  }
}

# Or copy the root disk of a stopped VM of the project ("golden image").
resource "h3_vm_image" "golden" {
  project_id   = var.project_id
  name         = "app-golden-2026-11"
  source_vm_id = var.stopped_vm_id
}

resource "h3_vm" "app" {
  project_id  = var.project_id
  name        = "app-1"
  cpu         = 2
  memory      = "4Gi"
  image       = h3_vm_image.alma.image # "custom:<id>"
  disk_size   = "20Gi"                 # >= size_gi of the image
  ssh_key_ids = [var.ssh_key_id]
}
```

## Schema

### Required

- `name` (String) Image name. Changing it replaces the image.

### Optional

- `description` (String) Description. Changing it replaces the image.
- `firmware` (String) Boot firmware of VMs made from the image: `bios` (default) or `efi`. Changing it replaces the image.
- `project_id` (String) Project ID (UUID). Defaults to the provider `project_id` (`H3_PROJECT_ID`). Changing it replaces the image.
- `size_gi` (Number) Virtual disk size of the image in GiB, for `url` (default 20, at most 256): not below the virtual size of the file. For `source_vm_id` it is the size of the VM's root disk (computed). A VM from the image needs `disk_size` of at least this size. Changing it replaces the image.
- `source_vm_id` (String) Copy the root disk of this VM of the project. The VM must be **stopped** (409 `VM_NOT_STOPPED`) and must be a Linux VM. Exactly one of `url` and `source_vm_id`. Changing it replaces the image.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `url` (String) HTTPS URL to import from (public address, port 443/8443/80/8080, no credentials in the URL; a presigned S3 URL works, its query string is not shown by the API). qcow2 or raw, optionally `.gz` or `.xz`. Exactly one of `url` and `source_vm_id`. Changing it replaces the image.

### Read-Only

- `created_at` (String) Creation time (RFC 3339).
- `id` (String) Image ID.
- `image` (String) Image reference for `h3_vm.image`: `custom:<id>`.
- `message` (String) Platform message about the import (the reason of `FAILED`).
- `os_type` (String) OS family (`linux`).
- `source_type` (String) Source of the image: `url` or `disk` (a VM root disk).
- `status` (String) `IMPORTING`, `READY`, `FAILED` or `DELETING`.
