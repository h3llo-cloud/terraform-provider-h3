# h3_vm_security_groups (Resource)

The security groups of a VM. The list is exclusive: it replaces whatever groups the VM had. Changes apply live, without
a VM restart. An empty list (`security_group_ids = []`) detaches every group: the VM is marked detached and the platform
does not put it back on `default`. On destroy the VM goes back to its project's `default` group (allow all) unless
`default_on_destroy = false`. Platform groups on the VM port (for example the managed Kubernetes project group) are not
affected and are shown in `foreign_groups`.

To add one group without owning the whole list (for example from several modules), use
`h3_vm_security_group_attachment` instead. Do not use both on the same VM.

## Example Usage

```terraform
resource "h3_vm_security_groups" "web" {
  vm_id              = h3_vm.web.id
  security_group_ids = [h3_security_group.web.id]
}
```

## Schema

### Required

- `security_group_ids` (Set of String) 0 to 5 security group IDs of the VM's project; `[]` detaches all groups.
- `vm_id` (String) VM ID.

### Optional

- `default_on_destroy` (Boolean) On destroy, put the VM back on the project `default` group (default `true`). `false` leaves the groups as they are.

### Read-Only

- `foreign_groups` (List of String) Platform groups on the VM port that are not managed here (e.g. the managed Kubernetes project group).
- `id` (String) Same as `vm_id`.
